## Network Protocols

Network protocols are basically the rules that make sure data sent over a network actually gets to the right place in the right order. So when you visit a website like www.yummyrecipesforme.org what actually happens behind the scenes is your device first does a TCP handshake which is just two devices verifying each other before any data moves then once that connection is made your browser uses HTTPS to securely request the webpage and DNS runs in the background translating that domain name into an actual IP address and ARP figures out the MAC address of the next device on the path. So just visiting one website uses TCP ARP HTTPS and DNS all at once. HTTPS specifically uses SSL/TLS encryption which keeps malicious actors from reading what is being sent

Protocols are split into three categories

- Communication protocols it  handle how data is exchanged like TCP which does a three way handshake SYN then SYN/ACK then ACK before streaming data and UDP which skips the handshake entirely so it is faster but less reliable good for things like video streaming and DNS requests. HTTP uses port 80 and DNS normally uses UDP on port 53 but switches to TCP if the reply is too large
- Management protocols is used to monitor and manage the network like SNMP which can reset passwords or check bandwidth usage and ICMP which reports errors and is what runs when you do a ping command
- Security protocols  for HTTPS uses port 443 and encrypts everything with SSL/TLS and SFTP uses SSH on TCP port 22 with AES encryption to securely transfer files this is what happens every time you upload or download from cloud storage

## Additional Protocols

NAT which stands for Network Address Translation is what lets all your devices at home share one public IP address while each having their own private IP. The router swaps the private IP with the public one for outgoing traffic and reverses it for incoming. Private IPs are assigned by the router and free to use while public IPs are assigned by ISP and IANA and cost money to lease. DHCP automatically gives each device on a network a unique IP address and also tells it which DNS server and default gateway to use running on UDP port 67 for servers and UDP port 68 for clients. ARP is what translates IP addresses into MAC addresses because MAC never changes but IP can so whenever a device needs to find the MAC of another device it uses ARP and stores the result in an ARP cache. Telnet connects to remote systems on TCP port 23 but sends everything in plain text so it is not secure and SSH replaced it by doing the same thing but with encryption on TCP port 22. For email POP3 downloads emails to your device on port 110 unencrypted or port 995 encrypted but the problem is it may delete from the server so you cannot sync across devices. IMAP is better because it keeps mail on the server so you can access from multiple devices using TCP port 143 unencrypted or TCP port 993 encrypted. SMTP handles sending and routing emails using port 25 for unencrypted and port 587 with TLS for encrypted

## Wi-Fi and Wireless Protocols

The Wi-Fi is basically the name for the IEEE 802.11 set of standards that define how wireless LANs communicate and the name Wi-Fi itself was made by an organization called Wi-Fi Alliance originally called WECA. Wireless security protocols evolved over the years starting from WEP in 1999 which was the first one but it had serious encryption flaws and is now considered high risk because attackers can break it. WPA came in 2003 to fix WEP and used TKIP with larger secret keys and added a message integrity check but it still had a vulnerability called KRACK attack where an attacker could insert themselves into the handshake and set the encryption key to all zeros making it as if nothing was encrypted. WPA2 came in 2004 and replaced TKIP with AES and used CCMP which is stronger but was also still vulnerable to KRACK attacks which led to WPA3 in 2018. WPA3 fixed the KRACK vulnerability by using SAE which prevents attackers from downloading data to decode offline and uses 128-bit encryption with optional 192-bit in enterprise mode. WPA2 has two modes personal which is easy to set up with one global passphrase good for home and enterprise which gives centralized control where admins can grant or remove access and users never see the encryption keys

## Security Zones and Subnetting

Security zones are basically segments of a network with their own rules and permissions that protect the internal network from the outside internet. The whole idea is that even if someone gets through one layer they cannot just spread everywhere. There is the uncontrolled zone which is anything outside the organization like the internet and then the controlled zone which is the protected internal side. Inside the controlled zone the outermost part is the DMZ which has public-facing stuff like web servers proxy servers DNS servers and email servers. Behind that is the internal network with private servers and data and then inside that there can be a restricted zone for highly confidential stuff only certain employees can touch. Ideally the DMZ sits between two firewalls one filtering outside traffic and one filtering what enters the internal network and if there is a restricted zone that gets its own firewall too

Subnetting is when you take one big network and divide it into smaller organized groups called subnets basically a network within a network. Each subnet is defined by the combination of IP address and network mask. This makes the network more efficient and is used to create security zones. CIDR is the method used for subnetting today it replaced the old classful system from the 1980s which ran out of addresses in the 1990s. A CIDR address looks like a normal IPv4 address but with a slash and a number at the end like 198.51.100.0/24 which covers all addresses from 198.51.100.0 to 198.51.100.255

## Firewalls

A firewall monitors traffic coming in and out and either allows or blocks it based on security rules and it can do port filtering like only allowing port 443 for HTTPS or port 25 for email and blocking everything else. Hardware firewalls inspect each packet before it enters the network. Software firewalls do the same thing but are just a program installed on a computer or server which costs less and takes no physical space but adds some processing load. Cloud-based firewalls are software firewalls hosted by a CSP and they filter all incoming traffic before it even reaches your network and also protect anything you have running in the cloud. A stateful firewall tracks everything passing through it and looks for suspicious behavior proactively while a stateless firewall just follows fixed rules set by the admin and does not track anything so it is considered less secure. NGFW or next generation firewall does stateful inspection plus deep packet inspection and intrusion protection and some connect to cloud threat intelligence to update against new threats

## VPNs

A VPN changes your public IP address and hides your virtual location and encrypts your data while it travels across the internet. The way it works is through encapsulation where your actual data packet gets wrapped inside another data packet that routers can read so your real IP stays hidden but the traffic still reaches the right destination. There is also an encrypted tunnel between your device and the VPN server that is unhackable without the cryptographic key. Remote access VPNs are for individual users connecting their personal device to a VPN server over the internet. Site-to-site VPNs are used by enterprises to connect whole networks across different locations and IPSec is commonly used for this though it is more complex to configure. WireGuard is a newer VPN protocol that is faster because it uses fewer lines of code is open source and easier to set up good for things like streaming and large downloads. IPSec is older more complex and widely supported by operating systems and some prefer it because of its long history and extensive security testing
