# Introduction to Cyber Security

## Offensive Security
Offensive security means thinking like an attacker.
You break into systems legally to find weaknesses before real attackers do.
This is what penetration testers and ethical hackers do.

## Defensive Security
Defensive security means protecting systems from attacks.
You monitor, detect, and respond to threats.
This is what SOC analysts and incident responders do.

## Careers in Cyber
Penetration Tester — finds vulnerabilities by attacking systems legally
SOC Analyst — monitors alerts and investigates threats daily
Incident Responder — responds when a breach actually happens
Malware Analyst — studies malicious software to understand how it works
Security Engineer — builds and maintains secure systems
