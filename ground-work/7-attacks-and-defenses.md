# Attacks and Defenses

## The CIA Triad
Confidentiality — only authorized people see the data.
Integrity — data is not tampered with.
Availability — systems work when needed.

Every security decision comes back to these three.

## Cryptography
Encryption — makes data unreadable without a key.
Symmetric — same key to encrypt and decrypt. Example: AES
Asymmetric — public key encrypts, private key decrypts. Example: RSA
Hashing — one way, cannot be reversed. Used for passwords.
Common hashes: MD5, SHA1, SHA256. MD5 and SHA1 are weak now.

## Become a Hacker
1. Reconnaissance — gather info about the target
2. Scanning — find open ports and services
3. Exploitation — attack a vulnerability
4. Post Exploitation — maintain access
5. Reporting — document everything

## Become a Defender
1. Prevention — firewalls, patching, strong passwords
2. Detection — SIEM, IDS, log monitoring
3. Response — investigate, contain the threat
4. Recovery — restore systems, learn from it
