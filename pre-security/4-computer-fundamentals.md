# Computer Fundamentals

## Inside a Computer System
CPU — the brain of the computer, processes all instructions.
RAM — temporary memory, stores what the computer is currently working on.
Storage — permanent memory, stores everything even when powered off.
Motherboard — connects all components together.

## Computer Types
Desktop — sits on a desk, powerful, not portable.
Laptop — portable version of a desktop, battery powered.
Server — powerful computer that serves data to other computers.
Embedded systems — tiny computers inside devices like routers and cameras.

## Client-Server Basics
Client — the device making the request. My laptop, my phone.
Server — the device responding to the request. Stores and serves data.
When I open a website my browser is the client.
The web server is the server sending back the webpage.

## Virtualisation Basics
A virtual machine is a computer running inside another computer.
I use VirtualBox to run Kali Linux inside my Windows machine.
This is how I practice hacking safely without affecting my real system.

Type 1 Hypervisor — runs directly on hardware. Used in data centres.
Type 2 Hypervisor — runs on top of an existing OS. VirtualBox is Type 2.

## Cloud Computing
Cloud means using someone else's servers over the internet.
Instead of buying hardware you rent it from AWS, Azure, or Google Cloud.

IaaS — Infrastructure as a Service. You rent servers and storage.
PaaS — Platform as a Service. You rent a platform to build apps on.
SaaS — Software as a Service. You use software over the internet. Gmail is SaaS.

Why companies use cloud:
No need to buy expensive hardware.
Scale up or down instantly based on demand.
Pay only for what you use.
