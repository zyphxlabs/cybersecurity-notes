# Linux Commands Cheatsheet

## Navigation
pwd — where am I right now
ls — list files
ls -la — list all files including hidden ones
cd foldername — enter a folder
cd .. — go back one folder
cd /etc — go to a specific path directly

## Reading Files
cat filename — print file contents
cat os-release — read Linux distribution info

## System Info
whoami — show current logged in user
uname -a — show kernel version and system info
uname — show just the OS name
df -h — show disk space in human readable format

## Searching
find / -name filename — search entire system for a file
