# Cybersecurity Notes

I'm a CS student but security wasn't part of my coursework  so I'm building that side myself, from scratch, starting May 2026.

This repo is my learning log. Every time something didn't make sense I kept at it until it did then wrote it down in my own words so I'd actually remember it. Some of it's rough some of it's solid  but all of it's real, and all of it's mine.

> Learning path draws from TryHackMe (Pre Security & Cybersecurity 101) plus the Google and IBM cybersecurity certificates. Notes and explanations throughout are written in my own words, not copied from any source.
